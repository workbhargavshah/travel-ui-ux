# TripTide — Travel Planning UI/UX Concept

TripTide is a responsive landing-page concept for a travel-planning product. The design focuses on making trip planning feel calm, inspiring, and easy to start.

## Project overview
- **Project type:** UI/UX concept and responsive front-end prototype
- **Topic:** Travel planning and destination discovery
- **Audience:** Students, friends, couples, and independent travellers
- **Goal:** Turn scattered travel ideas into a clear, shareable trip plan

## Main screens and sections
- Landing page with primary call to action
- Destination discovery cards
- Trip-planning form concept
- Three-step product flow
- Testimonial and final call to action
- Responsive mobile navigation

## Design direction
- **Visual style:** Minimal, warm, editorial, travel-inspired
- **Palette:** Deep forest green, warm cream, coral, muted sage
- **Typography:** Manrope for display headings and DM Sans for body text
- **Layout:** Generous whitespace, rounded cards, clear hierarchy, responsive grid

## UX decisions
1. The primary action (“Start planning”) appears near the top of the page.
2. The planning form groups destination, timing, and travel style into a short flow.
3. Destination cards use imagery and short labels to support quick scanning.
4. The “How it works” section explains the product in three understandable steps.
5. The layout adapts for smaller screens, with a collapsible navigation menu.

## Run locally
1. Download or extract this repository.
2. Open `index.html` in a browser.
3. For best results, use an internet connection for Google Fonts and the remote Unsplash photos.

No build tools or package installation are required.

## Note
This is a portfolio/learning concept, not a live travel-booking service. The planning form demonstrates front-end interaction and does not save or submit travel data.
